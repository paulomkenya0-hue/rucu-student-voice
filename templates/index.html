How it works

  1. Open link → read purpose → choose Give Feedback or Report Challenge.
  2. Fill the form → choose anonymous or identified → accept privacy notice → Submit.
  3. Receive reference number like RUCU-2026-000001 (+ SMS code if you gave a phone number).
  4. Track progress with your reference number. Admins review, assign, respond and resolve.
